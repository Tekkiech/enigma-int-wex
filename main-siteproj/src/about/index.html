About this data

The trend, map and table pages all read from src/data/: trend.js (the worldwide monthly series) and world-os-share.json (per-country breakdown, joined to country boundaries from Natural Earth's 110m admin-0 set). StatCounter Global Stats doesn't publish a public API, so this is a snapshot fetched from the same JSON endpoint its own site chart uses, taken 2026-09-15.

Swapping in a fresher pull, or a different metric StatCounter tracks (browser, screen resolution, search engine), means replacing those two files and nothing else.

Source: StatCounter Global Stats, Operating System Market Share Worldwide. Country boundaries: Natural Earth, public domain.
