About this data

The map reads a GeoJSON FeatureCollection: point features for individual schemes (name, status, capacity, local authority, connected buildings) and polygon features for wider heat network opportunity areas — the same shape used by DESNZ's Heat Network Zoning Pilot, which named Newcastle and Gateshead as one of its pilot areas. The pre-prod page this task is based on sits behind NELEP's staff login, so the figures shown here are illustrative placeholders assembled for this exercise rather than the production dataset. Everything the map draws comes from src/data.js, so pointing it at a different dataset — bus stops, planning applications, flood zones — needs no other code changes.
